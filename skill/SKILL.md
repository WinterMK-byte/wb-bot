# WB Bot · 操作指引

> 这一层的存在只为回答三个问题：**这事归谁？进度写哪？怎么让别人知道？**

---

## 一、开工第一步：读总线

**不要**直接开始干活。先看自己错过了什么。

```bash
python -m wbb.cli --bus "$WBB_BUS" read --since <你上次的水位线>
```

- 首次（水位线未知）→ `--since 0`，读全量
- 重点看 `need` 列**指向你**的条目
- 读完后**记住这次看到的最大 ID**，下次用它当水位线

> ⚠️ **水位线是加速器，不是过滤器。**
> 新会话第一次必须全量读 —— 否则你会漏掉历史。

---

## 二、写进度（唯一入口）

```bash
python -m wbb.cli --bus "$WBB_BUS" append \
  "来源|角色|做了什么|状态|产物|需要对方"
```

**六列的写法要求**：

| 列 | 好 | 差 |
|---|---|---|
| 来源 | `agent-a` / `会话 id` | `我` |
| 角色 | `architect` / `executor` / `reviewer` | `-`（如果席位有意义，就写） |
| 做了什么 | `把超时 30s→120s，起因 12-03 误杀` | `改了点东西` |
| 状态 | `done` / `in-progress` / `blocked` / `review` | `好了` |
| 产物 | 绝对路径，或"断点=哪个文件的哪个字段" | `已完成` |
| 需要对方 | `bob: 复核断言覆盖` / `-` | `看情况` |

**三条纪律**：

1. **绝不手写表行。** 走工具 —— 它带锁、算 ID、写后自检。
   手写的行时间列格式不对，体检会标出来。
2. **绝不预写 ID。** 并发下 ID 会变，**以工具返回值为准**。
3. **关键数字必须写进 `what`。** 三个月后你是唯一读者。

---

## 三、动手前：这事归谁

**先问一句**：

> **"我要改的这个文件，属于哪条线？"**

- 属于某条业务线 → **停手，转给该线主导者**
- 属于公共/基础设施 → 可以做

**例外（可代劳）**：切换成本明显高于直接做时，可以直接做，但**代劳后三件事缺一不可**：

1. 当场说明"这次我代劳了，因为 ___"
2. 登记总线（改了什么 / 为什么 / 影响面 / **回滚点**）
3. 事后通报该线主导者

> **核心资产**（代码主逻辑 / 判据口径 / 参数 / 产物终版）**必须**经该线主导者 —— 不适用代劳。

## 四、改共享文件前：先 claim

```bash
python -m wbb.cli --bus "$WBB_BUS" claim "shared.md|我要改这个加一节"
# ... 改完 ...
python -m wbb.cli --bus "$WBB_BUS" release "shared.md"
```

被拒时 → **不要强行覆盖**，先确认对方是否还在写。

查看当前占用：`locks` 子命令（会标注是否已陈旧可抢）。

---

## 五、随时可做的体检

```bash
python -m wbb.cli --bus "$WBB_BUS" verify
```

看到什么要警觉：

| 提示 | 含义 | 动作 |
|---|---|---|
| 重号 | 有人绕过工具手写，或历史遗留 | **人工裁决**（改 ID 会破坏引用） |
| 时间列不合规 | 该行不是工具写的 | 查是谁、为什么绕过 |
| ID 非单调 | 插入点算错过 | `--fix-order`（只重排，不改内容） |
| 列数不足 ⚠ | 多为多行条目续行 | **忽略**（故意不判 fail） |

## 六、给别的 Agent 发消息 = 写总线

不要指望"对方能看到你的对话"。
**唯一可靠的通道是总线** —— 在 `need` 列写清"谁、要什么"。

```
| ... | 需要对方=bob: 复核 T01 的断言覆盖，重点看边界情况 |
```

---

## 七、四条不变量（背下来）

1. **唯一写入入口** —— 只有 append，没有 update/delete
2. **ID 在锁内算** —— 分步读写必撞号
3. **写后自检 + 自动回滚** —— 脏数据进不去
4. **插入点用结构锚** —— 不用"最后一个数据行"

---

## 八、别做的事

- ❌ 手写总线表行
- ❌ 预写 ID
- ❌ 直接改别人的线内文件（要走代劳三件事）
- ❌ 把"写进文档"当成"通知到了"
- ❌ 在没人读的位置放关键信息
- ❌ 一次归档/清理一大批东西（默认只预演，确认后再 `--go`）

---

## 九、环境变量

```bash
export WBB_BUS=/abs/path/to/00-bus.md
```

设好之后所有命令都不用带 `--bus`。
